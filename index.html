Features

为什么选 ai-search-mcp

现有搜索方案都有硬伤：官方 fetch MCP 只会抓 URL 不会搜索；Tavily / Brave 质量高但全要付费 Key；社区 DuckDuckGo MCP 免费却脆弱、输出非结构化。这个项目填上了空档。

零 API Key

零配置开箱即用

npx ai-search-mcp 直接跑，不需要任何 API Key。默认区域感知，中国用户加一行 SEARCH_REGION=cn-zh 即可直连。

智能切换

区域感知自动选引擎

中国区域走 bing → so360 → baidu → sogou，海外走 google → bing → duckduckgo → yandex；429 / 超时自动故障转移。

一次调用

research 组合工具

一次调用 = 搜索 + 并行抓取 Top 页 → 证据简报。消灭 Agent 5~10 次工具往返，多页面并行、单页失败不影响整体。

更多能力

Agent 友好结构化输出

返回 { id, title, url, snippet, domain } 结构化 JSON，每条带稳定 id，可直接深读，无需手拼 URL。

时间过滤

freshness 或精确 timeRange 按引擎自动映射；中文「20xx年」查询自动改写 + 年份补偿。

内置 TTL 缓存

默认 10 分钟缓存减少重复请求，更快更省；可选 SEARCH_CACHE_FILE 持久化，重启不丢缓存。

工程兜底 & 健康追踪

超时、指数退避、统一错误码；引擎健康追踪，冷却中的引擎自动跳过，失败带归因诊断。

礼貌爬虫，合规优先

按引擎限频 + 随机请求间隔，主动避免触发风控；不做任何反爬对抗，遵循 robots.txt，合规红线。

How it works

三步完成一次智能搜索

从一句提问到拿到结构化结果，中间的引擎选择、故障转移、缓存与改写全部自动完成 —— 无需 API Key，无需配置。

01

引入 · 一句提问

Agent 调用 search 工具，只需传入搜索关键词；时间过滤、域名限定等按需添加。

  • 零配置，无需任何 API Key
  • 可选 freshness 时间过滤
  • 支持域名限定与多区域
02

处理 · 智能引擎链

系统自动挑选最合适的引擎，遇限流或超时即时切换；查询改写、缓存、限频在后台静默完成。

  • 区域感知选引擎（国内 / 海外）
  • 429 / 超时自动故障转移
  • TTL 缓存 + 礼貌限频
03

输出 · 结构化结果

返回标准 JSON（id、title、url、snippet、domain），Agent 可直接使用，无需解析 HTML。

  • 稳定 id，可一键深读
  • 自动去重与摘要
  • 无缝衔接 research 调研
01 中文查询自动改写 「20xx年」→ 自动加 freshness=year
02 引擎优雅降级 限流冷却自动跳过，不浪费请求
03 失败归因诊断 带 engineStatus 快照与可行动建议
Engines

九大搜索引擎，可插拔

7 个免费引擎 + 2 个付费官方 API。免费引擎开箱即用，付费引擎质量更高 —— 支持逗号分隔引擎链（如 brave,tavily），任一失败自动转移。

引擎免费API Key时间过滤适用区域说明
google 免费— ✕海外专用 索引质量全球最佳，反爬严，需海外 IP + Cookie 会话
bing 免费— ✓ qft全球 中国区域默认，中英文覆盖好，国内免代理直连
duckduckgo 免费— ✓ df全球备选 中国大陆直连可能超时（需代理）
yandex 免费— ✕海外专用 俄语 / CIS 内容强，部分网络可达性好，反爬中等
so360 / 360 免费— ✕国内直连 数据中心 / 国内 IP 均可直连，反爬相对宽松，中文原生引擎
baidu 免费— ✕仅限国内 中文索引强，但反爬严（数据中心 IP 带 Cookie 仍触发图形验证码）
sogou 免费— ✕仅限国内 微信内容覆盖好，缺 JS 生成的 SNUID 会话会被 302 拦回
brave 付费需要 ✓ freshness官方 API 质量高，有免费额度
tavily 付费需要 ✓ time_range官方 API 专为 LLM / RAG 检索设计
中国大陆免代理：默认 SEARCH_ENGINE=auto + SEARCH_REGION=cn-zh → 走 bing → so360 → baidu → sogou，全部直连可用，无需任何配置。其中 360 搜索（so360）对数据中心 / 机房 IP 的容忍度最高，是最可靠的国内原生中文引擎。
