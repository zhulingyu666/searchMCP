常见问题

8 个高频问题速览。更多讨论见 GitHub Issues ↗

需要付费 API Key 吗？

不需要。默认内置 7 个免费引擎（Google / Bing / DuckDuckGo / Yandex / 360 / 百度 / 搜狗），零配置开箱即用。Brave / Tavily 是可选的高质量付费引擎，需要时再配 Key。

在中国大陆能直接用吗？

可以。设 SEARCH_REGION=cn-zh 后默认引擎链为 bing → so360 → baidu → sogou，全部国内直连免代理。需要访问 DuckDuckGo / Brave / Tavily 时可用 SEARCH_HTTP_PROXY 走代理。

为什么返回 RATE_LIMITED？

免费引擎会限流，429 以结构化错误返回（带 suggestedEngine / retryAfter）。引擎链会自动故障转移，冷却中的引擎被跳过。可调低 SEARCH_RATE_PER_MINUTE（默认 8 次/分）或增大请求间隔。

百度/搜狗被验证码或 302 拦住了？

数据中心/海外 IP 下，百度会强制图形验证码（wappass），搜狗缺 JS 生成的 SNUID 会被 302 拦回。默认会自动转移到 Bing / 360；在大陆住宅 IP 且可达时可设 SEARCH_LANG_ROUTING=1 优先百度/搜狗。

引擎改版解析失效了怎么办？

解析规则外置在 src/selectors/*.json。设 SEARCH_SELECTOR_OVERRIDE_URL=<gist-url> 重启即修复，不用等新版 npm；覆盖加载失败自动回退内置规则，不阻塞启动。详见配置指南。

「2026年 大模型」为什么会被改写？

Bing 等引擎对中文分词弱，年份会被当主词导致跑题。工具会移除年份前缀并自动附加 freshness=year 补偿，改写通过 queryRewritten / queryYear 透明返回。

会抓取全文吗？合规吗？

只返回搜索摘要与链接，不转载全文。遵循 robots.txt 与服务条款；内置礼貌爬虫限频与随机间隔，不做任何反爬对抗 —— 合规红线。详见合规说明。

和 Tavily / Brave 官方 MCP 有何区别？

它们质量高但全要付费 Key；本项目把它们作为可插拔引擎纳入统一接口（SEARCH_ENGINE=brave,tavily），统一享受缓存、限频、故障转移、时间过滤与 research 组合工具。
