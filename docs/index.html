概览

专为 Agent 打造的上网搜索 MCP 服务器：零配置免费引擎、区域感知自动选引擎、freshness 时间过滤、内置缓存，以及一次调用完成整轮调研的 research 组合工具。

零 API Key。 npx ai-search-mcp 直接跑，默认内置 7 个免费搜索引擎；Brave / Tavily 为可选付费引擎。

为什么做（Why）

搜索是 Agent 最高频的工具，但现有方案都有硬伤：

现有方案问题
官方 fetch MCP只能抓已知 URL，不会搜索
Tavily / Brave / Exa 官方 MCP质量高，但全部要付费 API Key
社区 DuckDuckGo MCP免费但脆弱，输出非结构化，无缓存 / 重试

ai-search-mcp 填补了这个空档：零配置就能用（DuckDuckGo / Bing / 百度 / 搜狗 / 360 等），自动按区域选择最合适的引擎并故障转移，支持时效过滤，还能把「搜 → 选 → 抓 → 总结」的整轮调研压成一次 research 调用。

技术栈

  • 零构建纯 JS（CommonJS），Node.js ≥ 18
  • 137 个单元测试（Node 内置 test runner）+ 端到端冒烟测试
  • 基于 @modelcontextprotocol/sdk，stdio 传输，支持 Docker 容器化
  • MIT 许可证，独立开源项目

核心特性

🆓 零配置开箱即用

npx ai-search-mcp 直接跑，不需要任何 API Key。

🔌 多引擎可插拔

免费 duckduckgo · bing · baidu · sogou · so360 · google · yandex + 付费 brave · tavily。

🌏 区域感知自动选引擎

中国区域走 bing → so360 → baidu → sogou，其他区域走 google → bing → duckduckgo → yandex；429 / 超时自动故障转移。

🧠 Agent 友好输出

结构化 JSON（{ id, title, url, snippet, domain }），不是原始 HTML，每条带稳定 id。

🕒 时间过滤

freshness=day|week|month|year 或 timeRange，按引擎自动映射；中文「20xx年」查询自动改写。

🧭 research 组合工具

一次调用 = 搜索 + 并行抓取 Top 页 → 证据简报，消灭 5~10 次工具往返。

⚡ 内置缓存

TTL 默认 10 分钟，减少重复网络请求；可选文件持久化，重启不丢缓存。

🛡️ 工程兜底

超时、指数退避重试、统一错误码；引擎健康追踪，冷却中的引擎自动跳过，失败带归因诊断。

礼貌爬虫，合规优先。 按引擎限频（默认 8 次/分）+ 随机请求间隔，主动避免触发风控，不做任何反爬对抗；遵循目标站点 robots.txt 与服务条款。

工作原理

一次 search 调用，请求在引擎链间自动选择与故障转移，经过缓存、限频、解析规则，最终以结构化 JSON 返回给 Agent。

三个关键机制

01 查询改写

中文查询中的「20xx年」会被移除并自动附加 freshness=year —— 因为 Bing 等引擎对中文分词弱，年份前缀会导致返回「2026年百科/日历」等跑题结果。

02 优雅降级

RATE_LIMITED 立即触发冷却（默认 60s），其他失败连续 2 次进入冷却；冷却中的引擎会被引擎链跳过。

03 失败归因

全部引擎失败时，错误响应带 engineStatus 快照与逐引擎摘要，区分「全部冷却」（疑似 IP 被 Ban）与普通失败。
