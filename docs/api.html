工具参数

四个 MCP 工具的完整参数契约（调用示例见使用指南）。

search

参数类型默认说明
querystring—搜索关键词（必填）
maxResultsnumber10返回条数（1–20）
sitestring—限定单个域名（includeDomains 兼容别名）
includeDomainsstring[]—只返回这些域名（结果侧兜底过滤）
excludeDomainsstring[]—排除这些域名
regionstring—区域提示（DDG kl / Bing setlang / Brave country）；参与引擎自动选择
freshnessstring—day | week | month | year
timeRangestring—精确时间窗 "YYYY-MM-DD..YYYY-MM-DD"（优先级高于 freshness）

research

参数类型默认说明
querystring—调研主题（必填）
maxResultsnumber10搜索结果条数（1–20）
fetchTopNnumber3抓取 Top 页数量（按域名多样性选取）
extractModestringsummarysummary（去噪要点，省 token）| full（整页 Markdown）
freshness / timeRangestring—同 search 的时间过滤

fetch_page

参数类型默认说明
url 或 idstring—目标 URL，或搜索结果返回的稳定 id（二选一）
extractModestringsummarysummary（返回 mainText）| full（返回整页 markdown）
maxLengthnumber8000返回内容长度上限（字符）

status

只读工具，无必填参数。返回引擎健康状态、冷却截止、缓存命中统计与有效配置。

错误码

统一的错误模型：每个失败都以 McpSearchError 返回，带稳定的机器可读 code，Agent 可据此分支处理。

错误码含义处理建议
INVALID_ARGUMENTS参数不合法（query 为空、maxResults 超界等）修正参数后重试
ENGINE_NOT_FOUNDSEARCH_ENGINE 指定的引擎不存在检查引擎名拼写，用 status 查看
ENGINE_ERROR引擎返回无法解析 / 异常的内容切换引擎或稍后重试；可能站点改版，见解析规则覆盖
RATE_LIMITED引擎限流（HTTP 429）响应带 suggestedEngine / retryAfter；引擎链自动故障转移
TIMEOUT单次请求超时（默认 10s）调大 SEARCH_TIMEOUT_MS，或检查网络 / 代理
NETWORK_ERROR网络层失败（DNS / 连接 / TLS）检查网络连通性与代理配置
FETCH_ERRORfetch_page 抓取失败（403 / 反爬 / 结构异常）换 URL 或标记该页失败继续
 
{
  "code": "RATE_LIMITED",
  "message": "bing: rate limited, retry after 60s",
  "suggestedEngine": "so360",
  "retryAfter": 60,
  "engineStatus": { "bing": "cooling", "so360": "healthy" }
}
全部引擎失败的归因：错误响应带 engineStatus 快照 + 逐引擎失败摘要，并区分「全部冷却」（疑似 IP 被临时 Ban）与普通失败，附可行动建议。

引擎对比

7 个免费引擎 + 2 个付费官方 API。免费引擎开箱即用，付费引擎质量更高。支持逗号分隔引擎链，任一失败自动转移。

引擎免费API Key时间过滤说明
google免费—✕海外专用（墙内不可达）；索引质量全球最佳，反爬严，需海外 IP + Cookie 会话
bing免费—✓ qft全球通用；中国区域默认，中英文覆盖好，国内免代理直连
duckduckgo免费—✓ df全球备选；中国大陆直连可能超时（需代理）
yandex免费—✕海外专用；俄语 / CIS 内容强，部分网络可达性好
so360 / 360免费—✕360 搜索；数据中心 / 国内 IP 均可直连，反爬相对宽松，中文原生引擎
baidu免费—✕仅限国内；中文索引强，但反爬严（数据中心 IP 下仍触发图形验证码）
sogou免费—✕仅限国内；微信内容覆盖好，但缺 JS 生成的 SNUID 会话会被 302 拦回
brave付费需要✓ freshness官方 API，质量高，有免费额度
tavily付费需要✓ time_range专为 LLM / RAG 检索设计
