本页目录 环境要求 接入步骤 客户端配置 验证

环境要求

  • Node.js ≥ 18（零构建纯 JS，CommonJS）
  • 支持 MCP 的客户端：Claude Desktop、Cursor / Cline、WorkBuddy、VS Code 等
  • 无需任何 API Key，默认零配置即可用

接入步骤

1

打开 MCP 客户端配置

Claude Desktop 编辑 claude_desktop_config.json；Cursor / Cline / WorkBuddy 在设置中的 MCP 服务器配置处添加。标准客户端都接受 {"mcpServers": {...}} 结构。

2

粘贴配置片段

按下方 客户端配置 选择对应片段。中国用户建议加 SEARCH_REGION=cn-zh，自动走国内可直连引擎链（bing → so360 → baidu → sogou），免代理。

3

重启客户端

保存配置后重启，让其拉起 MCP 服务器；看到 ai-search-mcp ready 日志即启动成功（日志输出到 stderr，不污染 MCP 协议）。

4

验证搜索

对 Agent 说「搜索一下今天的 AI 新闻」或直接调用 search 工具 —— 返回结构化 JSON（{ id, title, url, snippet, domain }），不是原始 HTML。

客户端配置

# 直接用 npx 运行（无需安装）
npx -y ai-search-mcp

# 或全局 / 本地安装
npm i -g ai-search-mcp
ai-search-mcp
💡 推荐先这样跑一次确认环境正常，再把下面客户端的配置片段粘进 MCP 配置。
{
  "mcpServers": {
    "ai-search-mcp": {
      "command": "npx",
      "args": ["-y", "ai-search-mcp"]
    }
  }
}
💡 中国用户建议加上 env：{ "SEARCH_REGION": "cn-zh" }
{
  "mcpServers": {
    "ai-search-mcp": {
      "command": "npx",
      "args": ["-y", "ai-search-mcp"],
      "env": { "SEARCH_REGION": "cn-zh" }
    }
  }
}
💡 需要 Brave / Tavily 付费引擎？"SEARCH_ENGINE": "brave,tavily,bing" + 填入 BRAVE_API_KEY / TAVILY_API_KEY，详见配置指南。
docker build -t ai-search-mcp:latest .
docker run -i --rm --name ai-search-mcp ai-search-mcp:latest
{
  "mcpServers": {
    "ai-search-mcp": {
      "command": "docker",
      "args": ["run", "-i", "--rm", "--name", "ai-search-mcp", "ai-search-mcp:latest"],
      "env": { "SEARCH_REGION": "cn-zh" }
    }
  }
}
git clone https://github.com/zhulingyu666/ai-search-mcp.git
cd ai-search-mcp
npm install
npm start
